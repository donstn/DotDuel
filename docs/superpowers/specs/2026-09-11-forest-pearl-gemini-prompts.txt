FOREST & PEARL — GEMINI IMAGE PROMPTS
======================================
10 prompts total. Copy ONE prompt at a time (everything between the ---- lines)
and paste it as its own message to Gemini. After each image comes back, save it,
then move to the next prompt.

Crop instructions (what to cut each result into) are noted after each prompt,
but are NOT part of the prompt itself — don't paste those lines to Gemini.

REVISED 2026-09-11 after first-pass review: prompts 1 and 4 were rewritten after
real results came back with problems (dots ignored the magenta background; the
felt texture was too busy for a game surface). The old two-batch avatar prompts
(8 and 9) were also merged into ONE single prompt covering all six characters at
once — putting the whole lineup in one generation guarantees they share the same
body proportions and "leveling," which two separate generations couldn't
reliably hold onto (that's exactly what broke last time: level 1 came out as a
stubby mascot, levels 2-3 came out as full human-proportioned soldiers). This
merge means the file now has 10 prompts instead of 11.

Prompts 2, 3, 5, 6, 7, 9 (buttons), 10 (panel) were good on the first pass — no
need to rerun those.

SECOND REVISION (same day): the rerun of prompts 1 and 4 both came back correct
— done, no further action needed on those two. The merged avatar prompt 8
failed differently but still failed (background leaked into a real forest
scene, the lineup got duplicated into two rows, and robots 2-5 still weren't
the same body shape as robot 1). Prompt 8 is now a 6-message SEQUENTIAL chat
script instead of a single prompt — see that section for how it works and why.

PROMPT 8 of 10 — Avatars — SEQUENTIAL, 6 messages in ONE continuous chat
----------------------------------------
IMPORTANT — this one works differently from every other prompt in this file.

Two one-shot attempts at generating all the robots together (as one sheet,
and as two separate sheets) both failed the same way: robot 1 came out as a
short, round toy shape, but the others kept coming back as tall, human-shaped
armored soldiers, no matter how explicitly the text asked for a shared body
shape. Text alone isn't reliably holding the shape steady across separate
generations.

The fix: generate them ONE AT A TIME, as 6 separate messages, but ALL INSIDE
THE SAME CHAT CONVERSATION — do not start a new chat between them. Each
message after the first explicitly tells Gemini to copy the exact body shape
from the image it just made, which is a much stronger anchor than a text
description alone. Send message 1, wait for the image, then send message 2
in that same conversation (not a new one), and so on through message 6.

Save each result as its own file right after it's generated — see the file-
name noted after each message below.
